# 界面设计

顾问工作台以“学生—条件—证据”为主线。默认进入学生列表；匹配按项目轮次逐行显示，点击展开条件与原文。学校库先列学校入口；学校总览以紧凑表格呈现已收录项目及共同／特殊要求，再进入项目详情。

| 角色 | 色值 |
|---|---|
| 深绿导航与主要动作 | #17483F |
| 正文 | #243A35 |
| 次要文字 | #647871 |
| 页面背景 | #F3F6F5 |
| 符合条件背景 | #E4F0EB |
| 待核实背景 | #FFF3DB |

Segoe UI与微软雅黑／苹方承担中英文界面，数字遵从统一层级。左侧导航固定工作入口，主区域保持左对齐，原文及范围提示在右侧。颜色始终配合文字状态，不单靠颜色表达结论。

响应式：620px以下使用底部五项导航、表单单列、考试录入双列；表格在局部容器内滚动。模态框管理键盘焦点，保留可见焦点及减少动态效果偏好。所有功能图标使用SVG。

已读取Frontend Design与UI UX Pro Max指导。本轮使用UI UX Pro Max的UX检索检查密集比较表与导航，宽表在局部容器内滚动，保留键盘焦点与材料完整说明入口。


学校总览的资格表按学制／认证／文凭分行，各项目分列显示可／否，附加条件放在右侧；关键内容直接可见。语言行归并相同门槛，最后一列标明适用项目，单项目条件附“单独要求”。材料仅显示名称与说明标识。每轮初筛、面试、结果各占一列，避免日期纵向占据多行。使用现有字体、颜色与导航，不引入新图标库或运行依赖。
