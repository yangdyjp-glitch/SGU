# 界面设计

顾问工作台以“学生—条件—证据”为主线。默认进入学生列表；匹配按项目轮次逐行显示，点击展开条件与原文。项目库采用连续列表，避免用装饰卡片分散密集信息。

| 角色 | 色值 |
|---|---|
| 深绿导航与主要动作 | #17483F |
| 正文 | #243A35 |
| 次要文字 | #647871 |
| 页面背景 | #F3F6F5 |
| 符合条件背景 | #E4F0EB |
| 待核实背景 | #FFF3DB |

Segoe UI与微软雅黑／苹方承担中英文界面，数字遵从统一层级。左侧导航固定工作入口，主区域保持左对齐，原文及范围提示在右侧。颜色始终配合文字状态，不单靠颜色表达结论。

响应式：620px以下使用底部五项导航、表单单列、考试录入双列；表格在局部容器内滚动。模态框管理键盘焦点，保留可见焦点及减少动态效果偏好。所有功能图标使用SVG。

已读取Frontend Design与UI UX Pro Max指导。当前会话未提供后者的检索脚本／附带数据资源，因此采用已加载的交互、可访问性和布局规则；未声称执行过不可用的设计数据库检索。
